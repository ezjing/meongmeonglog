# T10. 웹 사진 넘기기 (점 표시·카운터·스와이프 렉)

사용자 제보 (2026-11-23, iPhone 홈 화면 웹 앱, 화면 녹화):
1. 일기 상세에서 사진을 옆으로 넘겨도 사진 아래 점 표시가 첫 번째에 멈춰 있다
2. 사진 크게 보기에서 화살표가 아니라 스와이프로 넘기면 버벅이다가 갑자기 휙 넘어간다. 이때 `1 / 4` 숫자도 바뀌지 않는다 (화살표로 넘기면 숫자가 맞게 바뀐다)

Android 앱에서는 제보 없음. **화면 문구·크기·동작 값은 바꾸지 않는다.**

## 원인 (Claude 확인)

1. `src/entities/walk/ui/WalkPhotoCarousel.tsx`와 `src/shared/ui/ImagePreviewModal.tsx` 모두 `onMomentumScrollEnd`로 현재 사진 번호를 계산한다. **react-native-web은 이 이벤트를 보내지 않는다.** 화살표는 `goToIndex`가 번호를 직접 바꿔서 맞게 보인다
2. 크게 보기의 사진마다 `ZoomableImage`의 `GestureDetector`(핀치·팬·더블탭)가 붙어 있다. 웹에서 Gesture Handler는 기본으로 그 영역에 `touch-action: none`을 걸어 **브라우저의 가로 스크롤을 막는다.** 손가락을 움직이는 동안은 넘어가지 않다가 손을 떼면 scroll-snap이 한꺼번에 맞춰져 휙 넘어간다

## 할 일

### A. 현재 사진 번호 (두 화면)
파일: `WalkPhotoCarousel.tsx`, `ImagePreviewModal.tsx`
- `onMomentumScrollEnd` 대신 `onScroll` + `scrollEventThrottle={16}`으로 `Math.round(x / width)`를 계산한다. 값이 바뀔 때만 state를 바꾼다 (스크롤마다 다시 그리지 않게)
- 범위를 `0 ~ 사진 수 - 1`로 자른다
- 크게 보기에서 화살표(`goToIndex`)와 스와이프가 같은 번호를 쓰게 한다. 화살표로 넘긴 뒤 스와이프해도 숫자가 맞아야 한다
- 같은 계산을 두 파일에 똑같이 두지 말고, 필요하면 `@/shared/lib`에 작은 함수로 둔다

### B. 크게 보기 스와이프 렉 (웹)
파일: `src/shared/ui/ZoomableImage.tsx`
- `GestureDetector`의 `touchAction`(웹 전용 prop, react-native-gesture-handler 2.31에 있음)을 **확대하지 않았을 때(`panEnabled`가 false) `pan-x`**, 확대했을 때 `none`으로 준다. 확대 전에는 가로 밀기를 브라우저가 처리하게 한다
- 네이티브(Android) 동작은 바뀌지 않아야 한다 (`touchAction`은 웹에서만 쓰인다)

**멈추고 사용자에게 물을 것:** 이렇게 했을 때 iPhone Safari에서 **핀치 확대나 더블탭 확대가 안 되면** 다른 방법을 정하지 말고 멈춘다. (대안 후보: 웹에서는 핀치를 빼고 더블탭으로만 확대 — 사용자 결정 필요)

## 수정 지시 1 — 화살표로 넘길 때 숫자 깜빡임·빠른 두 번 누름

**상태: 준비됨.** 안전 시간 600ms는 2026-11-23 사용자 승인.

파일: `src/shared/ui/ImagePreviewModal.tsx`

문제: `goToIndex`가 번호를 다음 장으로 바꾼 뒤 애니메이션 스크롤을 시작하면, 중간까지의 `onScroll`이 이전 장 번호로 되돌린다. 숫자가 `2 → 1 → 2`로 깜빡이고, 그동안 화살표를 다시 누르면 되돌아간 번호에서 계산해 한 장만 넘어간다.

할 일
- 화살표로 넘기는 중에는 "가는 중인 장"(목표 번호)을 따로 기억한다
  - 화면의 숫자·화살표 비활성 여부는 목표 번호가 있으면 목표 번호로 보여 준다
  - 화살표를 다시 누르면 목표 번호에서 다음·이전을 계산한다 (빠르게 두 번 누르면 두 장 넘어간다)
  - 스크롤 위치가 목표 장에 도착하면 목표 번호를 지운다
- 스와이프로 넘길 때(목표 번호가 없을 때)는 지금처럼 `onScroll`이 번호를 바꾼다
- 웹은 스크롤이 끝났다는 이벤트가 없으므로, 목표 장에 끝내 도착하지 않는 경우(예: 애니메이션 도중 손가락으로 다른 장으로 밀었을 때)를 대비해 목표 번호를 지우는 **안전 시간**을 상수로 둔다. 값: **600ms** (사용자 승인)
- 크게 보기를 닫거나 다시 열 때 목표 번호를 지운다

완료 조건
- [ ] 화살표로 넘길 때 숫자가 깜빡이지 않고 바로 다음 숫자가 된다
- [ ] 화살표를 빠르게 두 번 누르면 두 장 넘어간다 (마지막·첫 장에서는 멈춘다)
- [ ] 스와이프만 했을 때, 화살표와 스와이프를 섞었을 때 숫자가 맞다
- [ ] `npx tsc --noEmit`, `npm run lint` 통과
