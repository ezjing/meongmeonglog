# 작업 지시서 (Claude 계획·검토 → Cursor 구현)

계획과 검토는 Claude가 하고, 구현은 Cursor가 한다. 이 폴더의 작업 지시서가 둘 사이의 약속이다.

> 이 폴더는 GitHub Pages로 공개된다. 키·토큰·보안 약점은 쓰지 않는다 (로컬 메모 `HANDOFF.local.md`에).

## 진행 방식

1. **Claude**가 `docs/tasks/T<번호>-<이름>.md`에 작업 지시서를 쓴다: 목표, 바꿀 파일, 단계, 완료 조건, 하지 말 것
2. **Cursor**가 지시서를 읽고 구현한다
   - 지시서와 다르게 해야 할 부분이 생기면 **멈추고 사용자에게 목록으로 묻는다** (사후 보고 금지)
   - 지시서에 없는 새 문구·임의의 값(개수, 시간, 크기 등)은 정하지 않고 묻는다
   - 단계마다 `npx tsc --noEmit`, `npm run lint` 통과 후 커밋한다 (한국어 메시지, 작업 단위로 나눔)
   - **push·배포는 하지 않는다.** 배포가 필요한 작업은 지시서의 "배포" 절을 사용자에게 안내만 한다
3. Cursor는 끝나면 지시서 맨 아래 **"구현 결과"** 절을 채운다: 커밋 목록, 지시서와 달라진 점(사용자가 채팅에서 승인했으면 `승인됨`, 아니면 `미승인`), 확인하지 못한 것
4. **사용자**가 Claude에게 "T<번호> 검토해줘"라고 하면 Claude가 커밋을 검토하고, 필요하면 수정 지시를 지시서에 덧붙인다
5. 검토가 끝나면 사용자가 push·배포한다 (명령은 `docs/handoff.md` 5장)
