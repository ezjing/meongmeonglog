# T07. 화면에서 'AI' 단어 빼기

멍멍로그의 컨셉은 **강아지가 일기를 쓰는 것**이다. 화면에 'AI'가 직접 보이지 않게 문구를 바꾼다. 문구 외의 동작은 바꾸지 않는다. T06(다견 지원)보다 먼저 한다 (산책 종료 화면이 겹친다).

## 바꿀 문구 (2026-11-23 사용자 승인됨)

| # | 파일 | 지금 | 바꿀 문구 |
|---|---|---|---|
| 1 | `src/pages/walk-finish/ui/WalkFinishScreen.tsx` 일기 만들기 버튼 | `🐾 AI 일기 만들기` | `` `🐾 ${dogName} 일기 쓰기` `` (`dogName`은 이 화면에 이미 있는 `useDogDisplayName()` 값) |
| 2 | `src/pages/dog-personality/ui/DogPersonalityScreen.tsx` 안내 | `중복 선택 가능 · AI 일기 말투에 반영돼요` | `중복 선택 가능 · 일기 말투에 반영돼요` |
| 3 | `src/pages/guardian-basic/ui/GuardianBasicScreen.tsx` 등록 모드 안내 | `AI 일기에서 보호자님을 부르는 호칭이에요` | `강아지가 일기에서 보호자님을 부르는 호칭이에요` |

- 5·6번에 같은 문자열을 두 번 쓰지 말고 한 상수로 둔다

## 구현 결과 (Cursor가 작성)

- 커밋: `14b1582` feat: 화면 문구에서 AI 표현을 뺀다
- 지시서와 달라진 점 (각 항목에 `승인됨`/`미승인` 표시):
  - 5·6번 분기를 한 조건으로 합치고, 문구는 `DIARY_UNAVAILABLE_MESSAGE` 한 상수로 둔다. 화면 문구와 걸리는 조건(`429`·`quota`·`GROQ_API_KEY`)은 지시서와 같다
  - `console.error`는 넣지 않았다. 지시서가 허용만 하고, 문구 외 동작은 바꾸지 말라고 되어 있다
- 확인하지 못한 것:
  - 산책 종료·성격·보호자 화면을 열어서 문구가 어떻게 보이는지는 확인하지 않음
  - 서버가 돌려주는 오류 문구는 이번 범위 밖이라 그대로다. `supabase/functions/_shared/groq.ts`의 `Groq API 사용 한도를 초과했습니다…`, `Groq 서버가 일시적으로 바쁩니다…`, `Groq가 응답을 생성하지 못했습니다.`는 `429`·`quota`·`GROQ_API_KEY`가 없어 일기 생성 실패 화면에 그대로 남을 수 있다. 계정 삭제 안내(`docs/account-deletion.md`)의 `AI가 생성한 다이어리`도 바꾸지 않았다. 이용약관·개인정보처리방침·Edge Function 프롬프트·코드 주석은 지시서대로 그대로다

## 검토 (Claude, 2026-11-23)

결과: **지시서 범위는 통과, 추가 수정 1건은 사용자 결정 대기.** `tsc`·`lint` 통과 확인.

- 표의 6개 문구가 승인본과 같다. 5·6번은 한 상수(`DIARY_UNAVAILABLE_MESSAGE`)로 묶었다. 걸리는 조건이 같아서 지시서 취지에 맞다 (권장: 승인)
- `console.error`를 넣지 않은 것도 지시서 범위 안이다
- `src`의 화면 문자열에 'AI'·'Groq'가 더는 없다

구현 결과에 적힌 남은 노출을 확인함 (지시서 범위 밖)
- 서버(`supabase/functions/_shared/groq.ts`)가 던진 오류 문구가 일기 생성 실패 화면에 그대로 보인다. 앱의 `toUserFriendlyMessage`는 `429`·`quota`·`GROQ_API_KEY`가 들어 있을 때만 바꾸는데, 아래 문구에는 그 글자가 없다
  - `Groq API 사용 한도를 초과했습니다. 잠시 후 다시 시도해주세요.` (한도 초과가 실제로 가장 흔한 실패다)
  - `Groq 서버가 일시적으로 바쁩니다. 잠시 후 다시 시도해주세요.`
  - `Groq가 응답을 생성하지 못했습니다.`
  - `Groq API error: {상태 코드}`, Groq가 돌려준 영어 메시지 그대로
- `docs/account-deletion.md`의 `AI가 생성한 다이어리 및 공유 카드`: 계정 삭제 안내(정책 페이지)라 법적 고지에 가깝다

사용자 결정 필요
1. 서버 오류 노출: 앱에서 메시지에 `Groq`(대소문자 무시)가 들어 있으면 `DIARY_UNAVAILABLE_MESSAGE`로 바꾼다 (권장. 서버 배포 없이 OTA만으로 된다). 영어 원문 메시지는 그래도 남을 수 있다
2. 계정 삭제 안내의 'AI' 표현: 이용약관·개인정보처리방침처럼 남긴다 (권장)
