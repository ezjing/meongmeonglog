# 가족·다견 기능 계획

2026-11-23 사용자 요구사항("온 가족이 산책 스토리를 보면 좋겠다")에서 시작했다. 아래 결정은 사용자가 채팅에서 승인한 것이다. 지시서를 쓸 때 이 문서와 다르게 해야 하면 먼저 사용자에게 묻는다.

## 단계

| 단계 | 지시서 | 내용 | 배포 |
|---|---|---|---|
| 1 | [T05](tasks/T05-delete-walk-record.md) | 산책 기록 삭제 | 웹 + OTA |
| 2 | [T06](tasks/T06-multi-dog.md) | 다견 지원: 강아지 추가·전환, 여러 마리 산책, 강아지별 일기 | DB + Edge Function + 웹 + OTA |
| 3 | [T08](tasks/T08-family-household.md) + T09 (예정) | 가족: 집 단위 초대, 같이 간 가족, 탈퇴 시 넘기기 | DB + Edge Function + 웹 + OTA, 개인정보처리방침 개정 (네이티브 빌드 없음) |

단계마다 따로 배포한다. 앞 단계가 배포된 뒤 다음 지시서를 쓴다.

## 1단계 — 산책 기록 삭제

- 일기 상세 화면에서 "기록 삭제"(`danger` 버튼) → 확인 다이얼로그 → 산책 전체 삭제
- 일기·사진(DB와 저장소 파일)·공유 링크가 함께 사라진다

## 2단계 — 다견 지원

지금 DB는 한 사람이 여러 마리를 가질 수 있지만, 화면 6곳이 `dogs?.[0]`만 쓴다.

- 강아지 추가: 설정 드로어의 "강아지 추가"에서 기존 등록 화면(기본 정보 → 성격)을 다시 쓴다
- 강아지 전환: 홈 위쪽 아바타 줄. 캘린더·리스트는 선택한 강아지 기준
- 산책 시작 때 데려갈 강아지를 여러 마리 고를 수 있다
- 일기는 강아지마다 따로 만든다 (강아지마다 성격·말투가 다르다)
  - DB: 산책 ↔ 강아지 연결 테이블, `diaries`의 `walk_id` 유일 조건을 (산책, 강아지) 유일로 바꾼다

## 3단계 — 가족

### 묶는 단위
- **집 단위.** 집에 초대받으면 그 집의 강아지를 모두 함께 돌본다
- 한 사람이 여러 집에 속할 수 있다 (자기 집 + 부모님 집). 홈 강아지 목록에 모든 집의 강아지가 함께 나온다

### 역할
- 집 관리자: 강아지 정보 수정, 강아지 추가·삭제, 가족 초대·내보내기
- 가족: 산책 기록, 일기 보기·만들기

### 초대
- **초대 코드** (2026-11-23 링크에서 변경). 관리자가 앱에서 6자리 코드를 만들어 알려 주고, 받는 사람이 앱이나 웹에서 입력하면 그 집에 들어온다. 카카오톡 인앱 브라우저가 App Links를 따르지 않는 문제 때문에 링크 대신 코드로 정했다
- 코드는 **1회용, 7일 만료**. 잘못 입력은 1시간에 10번까지
- 한 집의 인원은 **최대 10명** (관리자 포함)

### 산책
- 한 강아지는 한 번에 한 사람만 산책을 기록한다. 누가 산책 중이면 "OO가 산책 중이에요" 안내 (문구는 지시서 작성 때 확정)
- 기록은 시작한 사람의 폰으로만 한다. 산책 종료 화면에서 "같이 간 가족"을 체크한다

### 일기
- 같이 간 가족을 표시한다 (예: "엄마·아빠와 산책")
- 일기는 같이 간 가족 모두를 각자의 호칭(`users.guardian_title`)으로 부른다
- 삭제는 집 관리자와 그 산책을 기록한 사람만 할 수 있다

### 탈퇴
- 관리자가 탈퇴할 때 가족이 있으면 **새 관리자를 직접 고른다.** 가족이 없으면 집 전체를 지운다
- 누가 탈퇴하든 그 사람의 산책 기록은 남기고, 기록한 사람만 "탈퇴한 가족"으로 바꾼다 (이름 등 개인정보는 지운다)
- 개인정보처리방침에 가족에게 공개되는 항목과 탈퇴 시 처리를 추가한다. 법률 검토 때 함께 본다

### 지시서 쓸 때 확인할 것 (기술)
- 모든 RLS 정책(`d.user_id = auth.uid()`)과 저장소 정책을 집 구성원 기준으로 바꿔야 한다
- 사진은 올린 사람 id 폴더(`{uid}/{walkId}/…`)에 저장된다. 관리자가 다른 가족이 올린 사진을 지울 수 있게 저장소 경로나 정책을 바꿔야 한다
- `delete-account` Edge Function: 관리자 넘기기, 기록 익명화, 남은 가족이 있는 강아지·사진은 지우지 않기
- 경로(`walk_locations`)는 산책 중 화면 말고는 읽지 않으므로 가족 공개 범위에서 따로 다루지 않는다
